## 2. New systemd units — commit `db7c2ff`

Two operational fixes were added as a dedicated commit on top of the 04-18 work before merging:

### Admin-password env file
`aquabot-app.service` got an `EnvironmentFile=-%h/.config/aquabot.env` line. The leading `-` makes it optional — service still starts if the file is missing and admin features simply stay disabled. **Password `Bot2025` is set on the Jetson** (file `/home/mayra/.config/aquabot.env`, chmod 600). That file is NOT in git by design — future pw changes happen directly on the Jetson + `systemctl --user restart aquabot-app`.

### Monthly log-cleanup timer
`aquabot-cleanup.service` + `aquabot-cleanup.timer` — monthly oneshot that deletes `blackbox_*.jsonl` and `telemetry_*.csv` older than 30 days from `/home/mayra/videos`. `OnCalendar=*-*-01 03:00:00`, `Persistent=true` so a powered-off Jetson catches up on next boot. Motivation: `app.py` now writes ~1 KB/sec of JSONL blackbox on top of the legacy CSV; left unchecked it'd fill the Jetson over months.

Timer is enabled + scheduled — `list-timers` shows next run Fri 2026-05-01 03:00 MST.

### One-time setup commands that were run
```
ssh jetson "mkdir -p ~/.config && echo 'AQUABOT_ADMIN_PW=Bot2025' > ~/.config/aquabot.env && chmod 600 ~/.config/aquabot.env"
scp jetson/systemd/aquabot-app.service jetson/systemd/aquabot-cleanup.service jetson/systemd/aquabot-cleanup.timer jetson:~/.config/systemd/user/
ssh jetson "systemctl --user daemon-reload && systemctl --user restart aquabot-app && systemctl --user enable --now aquabot-cleanup.timer"
```

These do NOT need to run again unless the Jetson is reimaged or the env file is deleted.
