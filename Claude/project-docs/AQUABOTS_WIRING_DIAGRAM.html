0 — Configuration Overview

▶ PRODUCTION

  • Battery: LiTime 24V 100–200Ah LiFePO4
  • Voltage: 25.6V nominal (8S LiFePO4)
  • Connection: M8 bolt posts → 4 AWG ring terminals
  • Main fuse: MRBF 100A
  • Trunk wire: 4 AWG Red / Blk
  • Endurance: 5+ hours (battery swaps)

▶ DEMO (Proof of Concept)

  • Battery: Ovonic 6S LiPo 22.2V / 6Ah
  • Voltage: 22.2V nominal (6S LiPo)
  • Connection: XT90 → adapter pigtail → harness
  • Main fuse: MRBF 40A (swap element only)
  • Pigtail: XT90♀ → 10–12 AWG → ring (6–8")
  • Endurance: ~51 min (fuse-governed at 40A)

Wire standard: All busbar-to-load branches use 12 AWG (except motor at 8 AWG). Standardized for marine durability, simplified inventory, and overhead for production currents.

Notes — Rev ISR-4
  • EMI filtering added: Bypass caps on busbar, ferrite toroids/clip-ons on branch (+) leads, parallel decoupling caps at each load. See AQUABOTS_EMI_FILTERING_BOM.pdf for full BOM and soldering instructions.
  • Wire standard: 4 AWG trunk, 8 AWG motor branch, 12 AWG all other busbar-to-load branches, 22 AWG load-side connections, 26 AWG sensor bus.
  • Starlink Mini: Direct from busbar — NO converter. Accepts 12–48V DC.
  • Motor branch: 8 AWG + MIDI 60A (corrected from 12 AWG/125A in ISR-3).
  • Main fuse: MRBF 100A prod / 40A demo (corrected from 150A/50A in ISR-3).
  • Most EMI-sensitive branch: 5V Buck → ESP32 (2.4GHz RF + analog sensor ADC). Has both input and output ferrites plus decoupling caps.
  • Most EMI-noisy branch: ESC/Motor (54A switching). Has ferrite toroid + parallel caps at ESC input.
  • See AQUABOTS_POWER_SYSTEM_CHANGELOG.md for full revision history.
