  ▎   22 AWG → ~5 A   |   18 AWG → 16 A   |   16 AWG → 22 A

  ▎   Peak battery-side draw                 ...  ~61 A
  ▎
  ▎ ── Why the ISR sizing did not pass review ────────────────────────────────────────
  ▎
  ▎ 1. Main fuse exceeded trunk wire ampacity.
  ▎    MRBF 150 A fuse > 4 AWG wire rating (135 A). In a dead short the wire overheats
  ▎    before the fuse blows — fuse cannot protect the conductor. FAIL.
  ▎
  ▎ 2. Motor fuse catastrophically exceeded branch wire ampacity.
  ▎    MIDI 125 A fuse > 10 AWG (−) wire rating (55 A). Fuse oversized by 2.3×.
  ▎    Also, 10 AWG (−) ampacity (55 A) gave <2% margin over 54 A motor peak — wire
  ▎    would run hot under sustained full throttle. FAIL.
  ▎
  ▎ 3. 16 / 18 AWG branches were electrically within ampacity but mechanically
  ▎    undersized for a vibrating, damp marine hull — no terminal-strength margin,
  ▎    no derating for bundling or elevated ambient temp, and small strands are
  ▎    prone to chafe-through and single-strand breakage. No margin for field repair.
  ▎
  ▎ ── Why the FAR sizing is sufficient ──────────────────────────────────────────────
  ▎
  ▎ Fuse-coordination rule enforced on every branch:  Max Load < Fuse Rating < Wire Ampacity
  ▎

  ▎ │ Branch              │ Max Load │ Fuse     │ Wire Amp. │ Coordinated │
  ▎ ├─────────────────────┼──────────┼──────────┼───────────┼─────────────┤
  ▎ │ Main trunk          │ 61.0 A   │ 100 A    │ 135 A (4) │ ✅ PASS     │
  ▎ │ ESC / Motor         │ 54.0 A   │ 60 A     │  73 A (8) │ ✅ PASS     │
  ▎ │ Starlink            │  4.7 A   │ 7.5 A    │  41 A (12)│ ✅ PASS     │
  ▎ │ 12V Buck input      │  0.9 A   │ 3 A      │  41 A (12)│ ✅ PASS     │
  ▎ │ 5V  Buck input      │ 0.15 A   │ 2 A      │  41 A (12)│ ✅ PASS     │
  ▎ │ BEC / Servo         │  1.0 A   │ 2 A      │  41 A (12)│ ✅ PASS     │
  ▎ └─────────────────────┴──────────┴──────────┴───────────┴─────────────┘
  ▎
  ▎ Headroom delivered:
  ▎   • Trunk: 2.2× ampacity margin (135 A wire vs 61 A peak)
  ▎   • Motor: 1.35× ampacity margin (73 A wire vs 54 A peak)
  ▎   • Buck + BEC branches: 40×+ ampacity margin on 12 AWG — picked for marine
  ▎     mechanical robustness, not electrical minimum. Fuses sized to buck
  ▎     input currents (not output-side loads) so short-circuit protection stays
  ▎     tight even though the wire is heavy.
  ▎   • 22 AWG retained for data lines only (logic-level, <20 mA).
  ▎
  ▎ Bottom line: every circuit now satisfies Load < Fuse < Wire. Mentor action item closed.
